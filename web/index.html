ZQ-NAV 客户端

在桌面上打开自己的导航站

琪舟阁是 ZQ-NAV 导航站的客户端外壳，覆盖 Windows、macOS、Linux 与 Android。 各平台通过系统自带的 WebView 渲染页面，程序内不包含浏览器内核。

站点内容与数据由使用者自行部署的 ZQ-NAV 实例提供，客户端仅负责显示与导航，不附带任何预置站点。

使用

客户端不携带站点数据，使用前需要一个可访问的 ZQ-NAV 实例。

  1. 部署 ZQ-NAV

    先在 Cloudflare Workers 上部署 ZQ-NAV，取得该实例的访问域名，例如 nav.example.com。 这一步在客户端之外完成，客户端不提供建站功能。

  2. 首次启动填写域名

    打开客户端，在输入框中填入上一步得到的域名，不需要自行补充 https://。 填写结果保存在本地，之后启动直接进入站点。填错时可从错误页重新填写。

  3. 通过菜单调用功能

    书签与站内链接均在客户端窗口内打开，不跳转系统浏览器。刷新、全屏、更换域名等操作统一放在菜单中。
