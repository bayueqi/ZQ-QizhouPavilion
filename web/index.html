琪舟阁

ZQ-NAV 导航站的客户端，Windows、macOS、Linux、Android 各一个。 先部署一个 ZQ-NAV 拿到域名，再用它打开。

Windows 和 Linux 解压就能运行，不用安装。macOS 包没有公证，第一次打开要右键「打开」。

用法

第一次打开填导航站域名，不用打 https://。之后启动直接进站，点书签在当前窗口打开，不跳系统浏览器。

Windows
在网页里右键
macOS
屏幕顶部的菜单栏
Linux
右键，或标题栏右边的 ☰
Android
长按屏幕

菜单里是刷新、全屏、更换域名、后退上一页、前进下一页、返回主页面。
