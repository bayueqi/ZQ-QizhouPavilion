琪舟阁

ZQ-NAV 导航站的桌面与移动客户端。服务端是一个跑在 Cloudflare Workers 上的书签收藏与分享平台，客户端只负责把它包装成独立应用——不内置浏览器内核， 直接调用系统 WebView，安装包 55 KB 到 871 KB。

组成部分

服务端与客户端分开部署，互不绑定。

  • 服务端 ZQ-NAV —— 基于 Cloudflare Workers 的书签收藏与分享平台，站点数据存放在 Cloudflare D1。部署一个实例后得到一个域名。
  • 客户端 琪舟阁 —— 本页提供的应用。填入任意一个 ZQ-NAV 实例的域名即可使用，只承载界面，不保存你自己的站点数据。

功能

只做一件事：让你自己部署的导航站，用起来像一个真正的软件。

首次填写域名，之后直接进站

第一次打开时输入导航站地址，之后每次启动都直接进入该站点，不再询问。需要更换时，侧边栏「后台管理」下方提供了「更改域名」入口。

站点内链接在窗口内打开

点击导航站里的任意书签都在当前窗口跳转，不会跳出到系统浏览器。返回按钮或手势用于逐页后退。

调用系统浏览器内核

Windows 使用 WebView2，macOS 使用 WKWebView，Linux 使用 WebKit2GTK，Android 使用系统 WebView。不打包 Chromium，安装包体积与内存占用因此大幅降低。

登录状态持久保存

Cookie 与站点存储在客户端的私有目录中。未卸载、未清除应用数据的情况下，再次进入同一站点仍保持登录。

按平台提供的原生入口

Windows 右键菜单、macOS 菜单栏、Linux 窗口菜单、Android 长按屏幕，均可返回导航站首页或刷新当前页面。

配置随程序存放

桌面端为便携模式：配置与缓存位于可执行文件同目录的 data/ 内，删除整个文件夹即完成卸载，不残留系统目录。

系统要求

客户端依赖系统已有的运行时与 WebView 组件。

  • Windows.NET Framework 4.8（Windows 10 1903 起系统内置）、WebView2 Runtime（Windows 11 内置，Windows 10 需单独安装）
  • macOSmacOS 11.0 或更高版本，使用系统 WKWebView
  • Linuxx86_64 架构，需安装 libgtk-3 与 libwebkit2gtk-4.1
  • AndroidAndroid 7.0（API 24）或更高版本，使用系统 WebView
